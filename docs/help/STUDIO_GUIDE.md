# Studio guide

A plain-English guide to the app for studio staff. The in-app assistant reads this guide, so keep it accurate when screens change.

## Who can do what

| | Owner / Admin | Front of House | Instructor |
|---|---|---|---|
| See the schedule | Everything | Everything | Their own classes |
| Class lists (who's booked) | Every class | Every class | Their own classes |
| Book, cancel, move or refund for a client | Yes | No | No |
| Take attendance | Any class | Any class | Their own classes, from an hour before |
| Create, change or cancel classes | Yes | No | No |
| Client profiles, history, packages and fees | Yes | Contact details on class lists only | Contact details for their own classes |
| Sell and manage packages | Yes | No | No |
| Cover | Choose who covers, approve, assign | No | Ask for cover on their own classes |
| Messages (Communication) | Yes | Yes | No |
| Reports, marketing, payroll, staff, studio rules | Yes | No | Their own pay (if the studio allows) |
| Agents and the assistant's settings | Yes | No | No |

Owners can do everything admins can. Only the owner can add or remove admins.

## Finding your way around

The menu on the left is grouped by what you're doing. Staff see:

- **Day to day:** Schedule (or My schedule), Cover requests, Communication, Announcements, Reward pickups (Front of House).
- **Clients & sales:** Clients, Leads, Packages, Fees.
- **Growth:** Marketing, Reports.
- **Team:** Staff & pay, Payroll, Agents.
- **Setup:** Class types, Templates, Locations & rooms, Studio rules.
- **Account:** My pay (instructors), Preferences.

Clients see **Classes** (Book a class, My bookings), **Packages & rewards** (My packages, Gift cards, Rewards, Refer a friend) and **Account** (Injuries & conditions, Profile & privacy, Preferences).

The **Ask** button (bottom right) opens the assistant. The **bell** at the top shows messages from your studio's agents.

## The schedule

- **Add a class:** Schedule, then **+ New class**. Start from a template to fill most details in. Choose "Repeats" to make it recurring.
- **Add an appointment** (a private session, not on the public schedule): **+ New appointment**. You can add the client straight away. You'll be warned if you leave the client empty, because appointments are usually only booked once confirmed.
- **Change one class:** tap it, then **Edit**. For recurring classes you choose "this class", "this and later" or "the whole series".
- **Change or cancel many classes at once:** **Edit many**. Either pick classes on the calendar, or choose them with filters (dates up to a year ahead, class types, instructors, location, days of the week and start time). Then change anything you could set when creating a class, or cancel them all.
- **Cancel a class:** tap it, then **Cancel class**. Everyone booked is told and gets their class back.
- **Auto-cancel:** a class can cancel itself if fewer than a set number of people are booked a set number of hours before. Set it on a template or on the class.
- **ClassPass:** in the class's settings, switch on ClassPass bookings and choose how many spots ClassPass can have. Unused ClassPass spots stay open to members.

## Booking clients in

Owners and admins book clients from the class: tap the class, then **Book a client**.

Common reasons a booking can't be made:

- **The class is full.** Add them to the waitlist instead.
- **They're already booked** into that class.
- **No package covers the class.** The package may have run out, expired, or not cover that class type. Sell them a package first, or (if the studio allows it under Studio rules, "Allow bookings without a package") book them as "Pay at studio". You can also book it as complimentary.
- **Appointments** always need a package that covers appointments.
- **They haven't signed the waiver.** Studio members sign in the app at their first booking. Front of House or an admin can mark a paper waiver as done.
- **Weekly limit:** the studio limits classes per week, and they've reached it. Admins can go over it after a warning.
- **The booking window:** clients can only book between the window opening (e.g. 14 days before) and closing (e.g. 1 hour before). Admins can still book people in outside it, after a warning.
- **The class has finished or was cancelled.**
- **ClassPass:** the class doesn't take ClassPass, or all its ClassPass spots are taken.
- **Your role:** only owners and admins can book clients in.

## Cancelling, moving and refunds

- **Cancel a booking:** tap the class, find the client in the class list, then **Cancel**. Outside the late-cancellation window, the class goes back to their package. Inside it, it counts as late: the class isn't given back and a late fee may apply (owners and admins can change both).
- **Move a booking:** the client's booking, then **Move**. It keeps the same package.
- **Refunds** are done by owners and admins only. For a class, use **Refund** on the booking in the class list (gives the class back). For a package, open the client (Clients, then their name), go to their packages and choose **Refund**. Card refunds go through once online payments are switched on.
- **Fees** (late cancellation, no-show) are listed under **Fees**, where admins collect or waive them.

## Waitlists

Clients join a waitlist when a class is full. In automatic mode the first person waiting gets the spot; in manual mode the spot is held for them for a set time (Studio rules). Waitlists close when booking closes.

## Packages

Package types are set up under **Packages**: class packs or unlimited memberships, price, how long they last, which classes they cover, sharing and weekly limits. Selling one copies the terms, so editing a package type never changes packages already sold. Each booking uses the package that runs out soonest.

## Cover

Instructors ask for cover from their class ("Ask for cover"). The request goes to the class's teaching list and admins are told. Admins choose who's asked, approve offers or assign someone directly under **Cover requests**.

## Clients and leads

- **Clients:** everyone who books with you, with history, tags, packages and fees. Owners and admins only.
- **Leads:** people who aren't paying members yet (ad enquiries, walk-ins, ClassPass clients). When a ClassPass client buys one of your packages, they become a member.

## Communication

Read and reply to WhatsApp messages from clients, alongside the WhatsApp Business app on your phone. Meta charges for some messages (marketing templates always; service updates outside 24 hours of the client's last message). Before using it, an owner or admin chooses how messages are paid for under Communication, Settings: pay Meta directly, or buy message credits. Replies within 24 hours of a client's message are free.

## Reports

**Reports** has tabs: Overview, Sales, Classes, Clients, Conversion and Instructors. Each number is compared with the period before. On the **Classes** tab, **Zoom in** narrows everything to a class type, location, instructor, days of the week or time of day (mornings, afternoons, evenings), and shows how full each location and time slot was.

## Agents

Agents are helpers that send reminders to staff (never clients) as push notifications to the staff app, and to the bell in the app. Owners and admins set them up under **Agents**:

1. Pick a ready-made agent (for example "Remind instructors about cover classes" or "Warn about quiet classes the night before").
2. Give it a name.
3. Adjust when it runs, what it checks and who it tells.
4. Choose what it can see: class times, who teaches, booking numbers (never names), and cover.

Agents never see client names, contact details, health notes, payments, prices, packages or pay, and they never change anything. They tell a person, who decides. Instructors only hear about their own classes. Anyone can mute an agent for themselves (Agents in the bell menu). **Pause all** stops every agent at once. **Preview** shows exactly what an agent would send right now, without sending it.

## The assistant

The assistant (the **Ask** button) answers questions about using the app and about your studio: for example, why a client can't be booked into a class. It only sees what your role can see. It can offer to book a client in, add them to a waitlist or cancel a booking that's free to cancel, and does it only once you press **Confirm**.

It can't do anything involving money (refunds, payments, prices, selling packages, fees, pay), change settings, staff or the schedule, delete anything, or share client contact details or health notes. For those, it tells you who can and where.

Owners and admins can switch it off, choose which roles can use it, and stop it doing things for people, under **Agents**, then **Assistant**. Each plan includes a number of assistant replies a month (see **Agents**, then **Usage**). Owners and admins are told at 80% and when they're used up, and can buy a top-up.

## Studio rules

Under **Studio rules**: the booking window, late-cancellation window and fees, no-show fees, weekly limits, whether clients need a package, whether staff can book without one, waivers, spot booking, waitlist holds and how cover works.
